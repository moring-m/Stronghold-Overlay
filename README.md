# Stronghold Overlay

명일방주 중국 PC 클라이언트 **위수 협의(卫戍协议)** 전용 화면 인식 오버레이 (Windows).

게임 메모리나 패킷은 건드리지 않습니다. 창을 캡처한 뒤 OCR로 화면을 읽고, 투명 창(클릭 통과)에 정보를 표시합니다. 자동 클릭 기능은 없습니다.

## 기능
| 화면 | 동작 |
|---|---|
| 1/3 确认本局信息 | 활성 맹약과 **밴(회색) 맹약**을 감지해 안내합니다. 선호 맹약이 밴되면 경고합니다. **보스(敌方领袖)와 특훈 적**을 표시하고 메모를 붙입니다. |
| 2/3 选择策略 | 오른쪽 상세 패널의 전략(리더) 이름(예: 阿米娅)을 읽고, 이 화면을 떠나기 직전 값을 확정 전략으로 보고 **같은 이름의 프리셋으로 선호를 전환**합니다. 조작 창에서 직접 고를 수도 있습니다. |
| 전투/상점 | 상점 카드 6칸의 **오퍼레이터 이름만** 읽어 선호 오퍼레이터 칸을 **노란 테두리**로 강조합니다. |

## 실행
```
pip install -r requirements.txt
python -m stronghold_overlay
```
게임은 16:9 창 모드에서 실행하세요. 창 제목은 `data/presets.json`의 `window_title`로 지정합니다.

## OCR 속도 (참고: 클라우드 4코어 CPU, 1353x761)
| 처리 | 시간 |
|---|---|
| 전체 화면 (화면 판별, 맹약/보스, 전략) | 약 0.4~0.6초 |
| 상점 이름 6칸만 (전투 중 기본 동작, 5회 중 1회는 전체 화면) | 약 0.29초 |

`interval_ms`(기본 700ms)만큼 쉬었다가 다음 프레임을 읽으므로, 상점 갱신은 대략 1초 안에 반영됩니다. 데스크톱 CPU에서는 더 빠를 수 있습니다.

## 설정 (`data/presets.json` → 조작 창 "설정 파일 열기"로 열면 `data/user_settings.json`)
- `base_operators` / `base_alliances`: 항상 적용되는 선호 오퍼레이터와 맹약
- `presets`: `"전략 이름(게임 표기)": {operators, alliances, note}` 형식입니다. 해당 전략이 감지되면 기본 선호에 이 값이 더해집니다.
- `enemy_notes`: 보스나 적 이름별 메모

## 알려진 한계
- 희귀 한자나 한 글자 라벨(예: 铳, 炎)은 OCR이 놓칠 수 있습니다. 메모는 접두어로 일치하는 항목을 찾아 붙입니다.
- 좌표는 1353x761 스크린샷 기준 비율값입니다(`detectors.py` 상단 상수).
