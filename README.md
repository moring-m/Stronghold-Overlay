# Stronghold Overlay

명일방주 중국 PC 클라이언트 **위수 협의: 규정(卫戍协议·规程)** 전용 오버레이입니다. Windows용 단독 실행 프로그램이며, 시스템 트레이에서 동작합니다.

게임 메모리나 패킷은 건드리지 않고, 창 화면을 캡처해 글자를 읽습니다(OCR). 자동 클릭 기능은 없습니다.

## 설치와 실행
1. GitHub 저장소의 **Actions → Build Windows app**에서 최신 실행 결과를 열고, 아래쪽 **Artifacts**의 `StrongholdOverlay-win64`를 받습니다. 태그를 달아 배포하면 Releases에도 올라갑니다.
2. 압축을 풀고 `StrongholdOverlay\StrongholdOverlay.exe`를 실행합니다. Python은 설치하지 않아도 됩니다.
3. 트레이(작업 표시줄 오른쪽 아래)에 마름모 아이콘이 생깁니다. 게임을 **16:9 창 모드**로 켜면 게임 화면 위에 정보가 겹쳐 표시됩니다.

| 동작 | 방법 |
|---|---|
| 설정 열기 | 게임 창 오른쪽 가장자리의 **⚙** 버튼, 또는 트레이 아이콘 더블클릭 |
| 설정 닫기 | ✕ 또는 Esc. 바꾼 내용은 **즉시 저장되고 바로 반영**됩니다. |
| 오버레이 숨기기 / 언어 / 종료 | 트레이 아이콘 우클릭 |

## 기능
| 게임 화면 | 오버레이 표시 |
|---|---|
| 1/3 本局信息 | 이번 판 **밴 맹약**, 선호 맹약이나 선호 오퍼레이터가 밴됐을 때 경고, **보스**(초상화로 식별)와 메모, **특훈 적** 분류 |
| 2/3 选择策略 | 고른 **전략**과 효과, 그 전략의 프리셋을 선호에 적용 |
| 전투/상점 | 선호 오퍼레이터 카드에 **노란 테두리** (카드의 오퍼레이터 이름만 읽음) |

## 설정 패널
- **선호 오퍼레이터:** 초상화 카드에 등급, 이름, 맹약이 표시되고, 카드를 눌러 선택합니다.
  - 한국어·중국어·영어 어느 이름으로든 검색할 수 있습니다.
  - 단계(1~6), 핵심 맹약, 부가 맹약, "선택한 것만 보기"로 걸러 볼 수 있습니다.
- **선호 맹약:** 밴 경고를 받을 맹약을 고릅니다.
- **전략 프리셋:** 전략별로 추가 선호 오퍼레이터, 맹약, 메모를 정합니다. 설정한 전략에는 ●가 붙습니다.
- **보스 메모:** 보스별 메모를 적습니다.
- **일반:** 언어(한국어 / English / 中文), 이번 판 전략 수동 지정, 인식 속도

설정 파일 위치: `%APPDATA%\StrongholdOverlay\user_settings.json`

## 데이터 출처
| 내용 | 출처 |
|---|---|
| 맹약, 전략, 보스, 특훈 적, 오퍼레이터 등급, 초상화 | [PRTS 위키 · 卫戍协议·规程](https://prts.wiki/w/卫戍协议·规程/PRTS盟约记录) |
| 한국어 번역 (오퍼레이터, 맹약, 전략) | [arknights1234.github.io · 위수 협의: 규정](https://arknights1234.github.io/act3autochess.html) |
| 영어 오퍼레이터 이름 | 글로벌 서버 게임 데이터 (미출시 오퍼레이터는 PRTS 외문명) |
| 영어 맹약 이름 | 국가명은 공식 표기, 나머지는 비공식 번역 (`tools/sync_i18n.py`) |

영어에는 이 시즌의 공식 전략 번역이 없어서, English로 설정해도 전략 이름과 효과는 중국어로 표시됩니다.

데이터 갱신 (개발자용, Pillow 필요):
```
python tools/sync_prts.py      # PRTS 데이터, 보스 초상화
python tools/sync_i18n.py      # 번역, 오퍼레이터 초상화
```

## 소스에서 실행 (개발자용)
```
pip install -r requirements.txt
python -m stronghold_overlay
```
`run.bat`을 더블클릭해도 같은 일을 합니다. 실행 파일은 `pyinstaller --noconfirm StrongholdOverlay.spec`으로 직접 만들 수 있습니다.

## 알려진 한계
- 한 글자 맹약 라벨(예: 炎)은 OCR이 놓칠 수 있습니다.
- 화면 좌표는 16:9 기준입니다(`detectors.py` 상단 상수).
