# Stronghold Overlay

명일방주 중국 PC 클라이언트 **위수 협의: 규정(卫戍协议·规程)** 전용 오버레이입니다. Windows용 단독 실행 프로그램이며, 시스템 트레이에서 동작합니다.

게임 메모리나 패킷은 건드리지 않고, 창 화면을 캡처해 글자를 읽습니다(OCR). 자동 클릭 기능은 없습니다.

## 설치와 실행
1. GitHub 저장소의 **Actions → Build Windows app**에서 최신 실행 결과를 열고, 아래쪽 **Artifacts**의 `StrongholdOverlay-win64`를 받습니다. 태그를 달아 배포하면 Releases에도 올라갑니다.
2. 압축을 풀고 `StrongholdOverlay\StrongholdOverlay.exe`를 실행합니다. Python은 설치하지 않아도 됩니다.
3. 트레이(작업 표시줄 오른쪽 아래)에 마름모 아이콘이 생깁니다. 게임을 **16:9 창 모드**로 켜면 게임 화면 위에 정보가 겹쳐 표시됩니다.

| 동작 | 방법 |
|---|---|
| 설정 열기/닫기 | 게임 창 오른쪽 가장자리의 **⚙** 버튼, 트레이 아이콘 더블클릭, 또는 **Ctrl+Alt+S** |
| 오버레이 켜기/끄기 | **Ctrl+Alt+O** 또는 트레이 메뉴 |
| 언어 / 로그 / 종료 | 트레이 아이콘 우클릭 |

## 기능
- **선호 강조:** 상점(전투 중 보급)에 선호 **오퍼레이터나 장비**가 나오면 그 카드에 노란 테두리를 그립니다. 상점을 접으면 테두리도 사라집니다.
- **프리셋:** 이름 있는 선호 묶음입니다. 연결한 전략을 게임에서 고르면 자동으로 적용되고, 일반 탭에서 항상 켜 둘 수도 있습니다.
- **알림 (끌 수 있음):** 프리셋이 적용되거나 선호 맹약이 이번 판에 밴되면 게임 화면 위쪽에 잠깐 표시합니다.
- 게임 창이 앞에 있을 때만 보이고, 창을 옮기면 따라갑니다. Windows 배율(125% 등)도 반영합니다.
- 오버레이를 끄면 화면 인식도 멈춰 CPU를 쓰지 않습니다.
- 두 번 실행해도 하나만 뜨고, 기존 창의 설정이 열립니다.

## 설정 패널
게임 위에 반투명으로 뜨며, 바꾼 내용은 바로 저장·반영됩니다.

| 탭 | 내용 |
|---|---|
| 선호 오퍼레이터 / 선호 장비 | 카드(초상화, 등급 아이콘, 이름, 맹약 아이콘 또는 가격)를 눌러 선택합니다. 검색(한/中/EN), 단계, 핵심/부가 맹약, "선택한 것만 보기"로 걸러 볼 수 있습니다. 카드의 **ⓘ**를 누르면 특질이나 장비 효과가 나옵니다. |
| 선호 맹약 | 밴 알림을 받을 맹약 |
| 프리셋 | 새로 만들기, 저장, 복제, 이름 변경, 삭제, **코드 내보내기/가져오기**(`SHP1.…` 한 줄 코드, 내보내면 클립보드에 복사됨). 프리셋마다 연결 전략, 오퍼레이터, 장비, 맹약, 메모를 정합니다. |
| 일반 | 언어(한국어 / English / 中文), 이번 판 전략 수동 지정, 항상 쓸 프리셋, 창 불투명도, 알림, Windows 시작 시 실행, 인식 속도 |

설정과 로그 위치: `%APPDATA%\StrongholdOverlay\` (트레이 메뉴 → 로그 폴더 열기)

## 데이터 출처
| 내용 | 출처 |
|---|---|
| 맹약, 전략, 오퍼레이터(등급·특질), 장비, 초상화·아이콘 | [PRTS 위키 · 卫戍协议·规程](https://prts.wiki/w/卫戍协议·规程/PRTS盟约记录) |
| 한국어 번역 (오퍼레이터, 특질, 맹약, 전략, 장비), 등급·맹약 아이콘 | [arknights1234.github.io · 위수 협의: 규정](https://arknights1234.github.io/act3autochess.html) |
| 영어 오퍼레이터 이름 | 글로벌 서버 게임 데이터 (미출시 오퍼레이터는 PRTS 외문명) |
| 영어 맹약 이름 | 국가명은 공식 표기, 나머지는 비공식 번역 (`tools/sync_i18n.py`) |

영어에는 이 시즌의 공식 번역이 없어서, English로 설정해도 전략, 장비, 특질은 중국어로 표시됩니다.

모든 데이터와 이미지는 `data/` 폴더에 들어 있고 실행 파일에 함께 포장됩니다. 실행 중에 인터넷에서 받는 것은 없습니다.

데이터 갱신 (개발자용, Pillow 필요):
```
python tools/sync_prts.py      # PRTS 데이터, 장비 아이콘
python tools/sync_i18n.py      # 번역, 오퍼레이터 초상화
```

## 소스에서 실행 (개발자용)
```
pip install -r requirements.txt
python -m stronghold_overlay
```
`run.bat`을 더블클릭해도 같은 일을 합니다. 실행 파일은 `pyinstaller --noconfirm StrongholdOverlay.spec`으로 직접 만들 수 있습니다.

## 알려진 한계
- 한 글자 맹약 라벨(예: 炎)은 OCR이 놓칠 수 있습니다.
- 화면 좌표는 16:9 기준입니다(`detectors.py` 상단 상수).
